## 自动同步行为

IP 池分配、换绑或核对后应用时，使用分配记录中的公网 `expected_exit_ip` 查询对应位置与 IANA 时区，要求查询返回的 IP 一致。代理入口地址不能代替公网出口；本次实际出口 `63.127.59.53` 对应 `America/New_York`，原代理入口的洛杉矶缓存已不作为依据。

时区写入 VM 配置、fingerprint 和运行容器。运行中的槽位在 TZ 改变时重建容器，未改变时 reload；普通时区同步保留账号 home 和授权。停止的槽位只更新配置，不自动启动。Geo、运行时 TZ 或槽内实际出口核验失败时保持维护暂停。

本次另有用户明确授权的单次清空操作，仅针对 `vm-01`。它不是分配 IP 或换时区的默认行为。
