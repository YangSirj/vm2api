## 交付范围

- 独占分配并从实际槽位核验公网出口。
- 一键复制 VLESS 链接，自动进入登录锁；锁定期间禁止换绑、释放和重新分配。
- 按首次位置就近换绑；保留原有额度、鉴权和人工暂停。
- 暂停排空、桥接与本机绑定、出口验证、旧连接清理及冷却结算。
- 本机应用失败保持维护暂停，通过查询已有分配恢复，避免重复换绑。
- 按事件发生时的已核验 IP 标黑，显示真实删除状态，支持核对及重试删除。
- 上游事件轮询、游标与去重持久化；维护暂停同时约束调度和后台监测。

实现为 vm2api 内部模块与账号代理页扩展，没有另建常驻适配服务。使用和升级方法见 [ip-pool-integration.md](ip-pool-integration.md)，上游契约见 [ip-pool-api-contract.md](ip-pool-api-contract.md)。
